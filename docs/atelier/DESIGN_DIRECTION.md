# 화면 디자인 지침

- 대화가 첫 화면이다. 왼쪽 아이콘 레일은 네 개의 주요 작업 공간을, 그 오른쪽 목록은 실제 저장된 대화를 보여준다.
- 배경은 옅은 라벤더, 작업 면은 흰색, 선택 상태는 분홍색으로 구분한다. 둥근 모서리와 얇은 경계, 절제된 그림자를 사용한다.
- 디자인 설문은 질문을 한 장씩 구분하고 입력 예시와 다음 행동을 가까이 둔다. 실제 저장·연결 상태를 장식으로 대체하지 않는다.
- 픽셀 편집 화면은 건축 보드처럼 작업 영역과 도구를 구분하며 기존 배치 및 실행 상태를 유지한다.
- 작은 화면에서는 메뉴를 대화상자로 옮기고 키보드 포커스, 텍스트 상태, 모션 감소 설정을 유지한다.
