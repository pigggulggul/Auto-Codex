# Home Designs 원본 분석과 프리셋 제작 기준

이 문서는 `public/assets/Home_Designs`의 원본 이미지 분석이다. 아래 배치도는 이미지의 방향과 상대 위치를 나타내며, 완성된 편집 가능 프리셋이나 모든 객체의 검증된 좌표를 뜻하지 않는다. 원본은 이미지 레이어이며 사물별 배치 데이터가 포함되어 있지 않다.

14개 원본의 48px 좌표 격자와 레이어별 불투명 연결 영역 목록은 [원본 좌표 조사](home-design-coordinate-survey/README.md)에 있다. 이 자동 조사 결과는 사물의 의미나 겹친 경계를 구분하지 않으므로 개별 사물 좌표를 직접 확인해야 한다.

### 픽셀 대조로 확인된 사물

좌표의 원점은 원본 레이어의 왼쪽 위다. 싱글 이미지의 투명 여백을 포함한 이미지 상자 기준이다. 다음은 2026-11-09에 레이어 2와 싱글 PNG의 불투명 픽셀을 대조해 확인한 일치 항목이며, 겹침 때문에 이 목록이 전체 사물이라는 뜻은 아니다.

| 원본 싱글 파일 번호 | 크기 | 원본 좌표 (x, y) | 위치 |
|---|---:|---:|---|
| Condominium 13 | 64×192 | (112, 0), (496, 0) | 왼쪽·오른쪽 위 계단 |
| Condominium 46 | 48×96 | (288, 384) | 아래쪽 중앙 계단 왼쪽 |
| Condominium 48 | 48×96 | (336, 384) | 아래쪽 중앙 계단 오른쪽 |
| Condominium 80 | 96×80 | (240, 163) | 위쪽 중앙 왼쪽 수납장 |
| Condominium 82 | 128×128 | (352, 157) | 위쪽 중앙 오른쪽 수납장 |

원본 이미지에는 48px 격자에 맞지 않는 위치가 있다. 숫자와 위치를 무작위 격자점에 끼워 넣으면 원본과 달라진다. 벽·출입구는 레이어 1의 원본 형태를 기준으로 별도 추적이 필요하다. 아래쪽 발판과 가려진 계단 부품은 아직 정확한 자산 및 좌표를 확정하지 않았다.

### 현재 편집기와의 차이

- 현재 프리셋 생성기는 기본 맵의 작업석 8개와 직사각형 외벽을 그대로 사용한다. 로비 원본에는 이 책상 배치가 없다.
- 사물 위치가 `col`, `row` 정수 격자로 제한되어 (240, 163), (352, 157) 등 원본 좌표를 정확히 나타낼 수 없다.
- 고정 작업석과 통로 검증은 원본의 계단·벽 배치와 충돌할 수 있다. 화면 장식과 실제 이동 가능 영역을 구분하여 모델링하고, 기존 사용자 저장 맵과 호환되도록 해야 한다.
- 완성 기준은 각 사물이 별도로 편집 가능한 상태에서 원본과 실제 렌더링을 비교하는 것이다. 전체 원본 PNG 한 장을 배경으로 표시하는 방법은 사용자가 선택한 방식이 아니다.

## 완료 검증 기준

1. 이미지와 레이어를 도식화하고, 겹침을 포함한 사물·벽·바닥의 종류와 좌표를 확인한다.
2. 원본에 없는 책상을 자동 추가하지 않고, 기존 맵 저장 데이터는 그대로 읽을 수 있게 한다.
3. 개별 사물을 이동·삭제하고 저장한 후 다시 불러올 수 있는지 확인한다.
4. 원본과 결과 화면을 같은 크기와 배율로 비교한다. 좌표·누락·겹침을 확인하기 전에는 원본과 같다고 표현하지 않는다.
5. 14개 디자인과 다양한 화면 크기, 키보드 조작 및 실패 상태를 확인한다.
