# 룸 빌더 자산

픽셀 화면의 **맵 편집**에서 바닥·길·벽·문/통로를 고른 뒤 `종류`로 원본 시트를 선택한다. 각 항목은 48px 격자의 원본 위치를 보여 주며 여러 페이지에 걸쳐 있다. 벽의 수평·수직·모서리 조각은 원하는 위치에 직접 놓는다. 기존 기본 회색 벽만 인접한 벽에 맞춰 기본 부품을 고른다.

`완성된 아치`에는 2×3칸으로 한 번에 배치하는 다섯 가지 아치가 있다. 개별 아치 조각과 문턱·바닥 연결 조각도 선택할 수 있다. 길과 문/통로는 이동 가능한 칸으로 검사하며, 외벽·바닥·통로 검사를 통과해야 맵을 저장한다. 예시인 `Home_Designs`는 완성된 그림이므로 별도 자동 변환 없이 룸 빌더 조각을 사용해 구성한다.

목록은 `public/assets/Interiors/Room_Builder_subfiles_48x48`의 아홉 PNG에서 투명하지 않은 조각을 추출한다. 원본 리소스를 바꾼 경우 저장소 루트에서 `powershell.exe -NoProfile -File tools/build-room-builder-catalog.ps1`을 실행해 `src/world/roomBuilderTiles.json`을 갱신한다. 목록 순서는 저장된 맵의 스타일 번호에 사용되므로 기존 항목의 순서나 리소스를 변경할 때는 저장 맵 호환성을 확인해야 한다.
