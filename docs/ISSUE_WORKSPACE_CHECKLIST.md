# 이슈 작업실 작업 체크리스트

기준: 현재 작업 트리. 상위 기능의 체크는 사용자에게 연결된 동작을 뜻한다. 아래 별도 세부 작업의 체크는 표시된 범위의 구현·검증만 뜻하며, 운영 기능 완료를 뜻하지 않는다.

현황 확인: 2026-11-10, `main`의 `47f74c5`와 미커밋 작업 트리 기준. 이 문서는 배포 완료나 실제 사용자 환경에서의 수용을 뜻하지 않는다.

## 2. 초안과 검증 API

- [x] 연결별 초안 생성·조회·수정과 명시적 등록, 프로젝트 및 초안 revision 충돌 검사 (신규 입력은 요구사항과 이슈 1:1, 이후 분류 및 요구사항 연결 편집 가능; 대화 제안 실행은 별도 미검증 경로)
- [x] 분석 결과에서 개별 후보를 선택해 초안 입력으로 가져오기 (AI 제안으로 표시, 선택 당시 자료 해시·인용·불확실성 보존; 등록 시 현재 연결에서 선택된 원본의 경로·크기·해시를 재확인)
- [x] 연결별 초안의 링크 확인·보류 UI와 검토 기록 API, 수정 시 검토 무효화. 명시적 저장으로 초안과 이력을 로컬 저장소에 보존하며 프로젝트 revision 변경 시 자동 복구를 거부한다. (오래된 저장 초안의 정리·변경 비교는 미구현)
- [ ] 계획 대화의 저장, 초안 revision에 연결된 AI 제안 생성·비교·선택 적용 및 stale 제안 거부
- [ ] 계획 대화의 제한된 텍스트 변경 제안, 별도 격리 작업자·명시적 선택 적용·대화 기록을 구현 중. 모델 실행·화면·실패·복구 경로는 아직 검증하지 않았고 실행은 빌드 시 비활성화되어 있다. 분류 생성이나 선행 관계 변경 제안은 포함되지 않는다.
- [x] 초안 분류 계층 추가·이름 및 상위 분류 수정·미사용 분류 삭제, 요구사항·이슈별 분류 지정과 다대다 요구사항 연결 편집
- [x] 연결 여부와 관계없는 요구사항과 이슈 개별 생성·수정, 참조되지 않는 항목 삭제 (대화 제안 실행은 별도 미검증 경로)
- [x] 초안의 명시적 등록, 프로젝트·초안 revision 충돌 거부 및 등록 전 선택 원본 재확인
- [ ] 등록 이후 저장 초안 정리, 오래된 저장 초안의 조회·비교·복구 또는 명시적 삭제. 현재 저장 초안은 프로젝트당 하나이고 등록 후에도 남아 다음 저장을 막을 수 있음
- [ ] 저장 초안 미리보기 및 명시적 현재 revision 검토본·새 문서 복사 흐름 구현 중. 서버가 저장 세대와 보기 권한을 재확인하고 복사 시 새 ID와 연결을 생성하도록 작성했으나 아직 테스트·실제 화면 검증 전이며 완료로 간주하지 않는다.
- [ ] 프로젝트 revision 충돌 시 연결 메모리의 초안을 버리지 않고 읽기 전용으로 표시하며, 명시적 선택 시 현재 revision 검토본으로 전환하도록 작성함. 이전 검토는 이력으로 이동하고 저장은 별도로 요청해야 함. 아직 테스트·실제 화면 검증 전이며 연결 종료 시 저장하지 않은 초안은 사라짐.
- [x] 등록 문서의 연결·빈 항목 등 결정적 읽기 전용 점검과 상세 조회
- [ ] 의미 검증 API, 근거·불확실성·미처리 구간 표시
- [ ] 의미 검증의 모델 결과 스키마·원문 인용·초안 revision 확인 및 단일 구간 격리 실행·화면·초안 기록을 구현 중 (`server/issues/semantic-validation.ts`). 검토 사유 기록 시 원본을 재확인하도록 작성했으나 전체 경로는 테스트 전이며 실행은 빌드 시 비활성화되어 있다.
- [ ] 의미 검증 결과의 해결·보류 사유 저장과 revision 변경 시 stale 처리 (초안 링크 검토 이력의 명시적 저장은 별도 구현)

## 3. 이슈 실행과 운영

- [x] 동일 문서에서 최대 8개 이슈 선택 및 상태·완료 조건·선행 관계의 읽기 전용 사전 점검
- [ ] 순차 실행·중단과 실제 이벤트 연결. 사전 점검은 실행 허가가 아님
- [ ] 실행 기록과 검증 근거 저장, 결과 불명 복구
- [ ] 이슈 상태 제안·사용자 적용, 정책 조회·설정·철회
- [ ] 관련 보안·실패 경로와 실제 화면 검증, 타입 검사·테스트·빌드

자료 범위 내의 기계적 연결 표시는 원문 의미의 완전성이나 코드 구현의 증거가 아니다. AI 분석은 조건을 충족하면 선택 자료를 모델 제공자에게 전송할 수 있다. 이슈 실행은 사용자 화면에 아직 연결되지 않았다. 실제 모델 시험의 범위와 잔여 위험은 `ISSUE_ANALYSIS_CONTRACT_V1.md`를 참고한다.

초안 등록의 원본 재확인은 각 파일을 읽는 시점의 검사이며 파일 시스템을 잠그지 않는다. 화면이 제출한 출처 정보의 내용이나 AI 후보 해석의 정확성을 증명하지 않는다. 파일이 바뀌거나 현재 연결에서 선택이 제거되면 등록을 거부한다.

## 검증과 배포 상태

- 2026-11-10 현재 추가 변경에서 `npm run typecheck`, `npm test` (91개 파일·805개), `npm run build`가 통과했다. Vitest는 샌드박스 임시 캐시의 이름 변경이 거부되어 승인된 샌드박스 밖 실행으로 확인했다. 빌드는 대형 청크 경고를 출력했다.
- 같은 날 설치된 `codex-cli 0.166.0`의 임시 합성 프로필과 루프백 제공자로 도구·훅 probe를 실행했다. 합성 훅 탐지와 해당 MCP·플러그인 차단을 확인했지만 전역 지침은 요청에 포함됐고, 명령 승인 대조군에서는 루프백 통신이 가능했다. 임의 사용자 설정과 관리 훅의 전체 격리는 입증되지 않았다.
- 2026-11-10 최종 기능 변경 당시 `npm run typecheck`, `npm test`(90개 파일·800개 테스트), `npm run build` 통과. 이후 저장 충돌 안내 수정에 대해 관련 테스트 5개 파일·159개와 빌드를 다시 통과했다. 이번 현황 정리에서는 테스트를 다시 실행하지 않았다.
- 합성 화면의 초안 작성·저장·새로고침·불러오기와 별도 격리 SQLite의 재시작 복구를 각각 확인했다. 실제 브리지·네이티브 선택·실제 모델을 연결한 하나의 전체 화면 흐름은 확인하지 않았다.
- 저장소 v5는 기존 v4를 일관 백업한 후 이전한다. 구버전 앱은 v5를 열 수 없으며 백업 이후의 변경은 v4 백업에 없다. 실제 사용자 저장소 이전·배포는 수행하지 않았다. 상세 복구 조건은 `ISSUE_STORAGE_V1.md` 참고.
- 검증 자료 `.playwright-mcp/`와 기존 사용자 변경을 포함해 미커밋 파일이 있다. 자동 정리하거나 되돌리지 않았다.
