# 이슈 작업실 작업 체크리스트

기준: 현재 작업 트리. 상위 기능의 체크는 사용자에게 연결된 동작을 뜻한다. 아래 별도 세부 작업의 체크는 표시된 범위의 구현·검증만 뜻하며, 운영 기능 완료를 뜻하지 않는다.

## 1. 분석 API와 실행 (우선)

- [x] 선택 자료 목록·추가·미리보기·제거 API 및 연결별 보기 권한
- [x] 분석 입력 스냅샷 준비와 원본 변경 확인 API
- [ ] `issues.analysis.start`: 브리지·화면과 격리 작업자 연결, 합성 자료의 실제 모델 호출 시험 완료; 사용자 환경 전반의 격리는 미검증
- [ ] `issues.analysis.status`: 실행 상태·구간 수 조회 연결; 실제 사용자 화면 전체 흐름은 미검증
- [ ] `issues.analysis.interrupt`: 브리지·화면 요청과 합성 중단 테스트 연결됨; 운영 turn 중단 미검증
- [ ] 선택 파일만 접근 가능한 도구·훅 경계 검증; 확인 불가 시 시작 거부
- [ ] App Server 결과 수집기와 분석 배치 연결, 재시도 및 늦은 결과 차단 (격리 작업자 연결 및 합성 입력 시험 완료; 사용자 환경 전체 검증 미완료)
- [ ] 실행 상태·실패·중단·부분 결과를 화면에 연결하고 전송 범위를 명시 (화면 구현 및 합성 검증 완료; 실제 모델 결과의 화면 전체 흐름 미검증)

### 완료한 세부 작업 (합성 환경)

- [x] 분석 시작·상태·중단·구간 조회·재시도 요청의 브리지 계약과 화면 연결
- [x] 연결별 보기 권한, 임의 설정 필드 거부, 프로젝트 revision 및 원본 변경 확인
- [x] 구간별 후보·출처 표시와 실패 구간 재시도, 중단 전 처리 결과 보존
- [x] 합성 실행에서 중단 요청 우선 처리와 종료 미확인 시 잠금 유지 테스트
- [x] 가짜 모델과 실제 CLI 프로토콜을 이용한 내부 전송기 결과 수집 시험
- [x] 운영 브리지의 실행기·공유 잠금·이벤트 라우터 연결과 합성 정책 테스트 (실제 정책은 미검증)
- [x] 합성 화면에서 자료 준비, 실행 불가 안내 및 후보·인용 표시 확인

### 남은 운영 연결

- [ ] 임의 사용자 설정과 CLI 버전에서 도구·훅 격리 검증 (현재 작업자는 확인 실패 시 거부하며 명령 승인 경로는 비활성)
- [ ] 실제 App Server 이벤트 라우팅 및 전역 실행 잠금의 운영 통합 검증 (연결 코드와 합성 테스트 완료)
- [ ] 실제 모델 요청·상태·중단과 부분 결과의 화면 전체 흐름 검증 (합성 입력의 브리지 요청과 후보 조회 시험 완료)

## 2. 초안과 검증 API

- [x] 연결별 초안 생성·조회·수정과 명시적 등록, 프로젝트 및 초안 revision 충돌 검사 (요구사항과 이슈 1:1 입력, 분류·대화 제안은 미구현)
- [x] 분석 결과에서 개별 후보를 선택해 초안 입력으로 가져오기 (AI 제안으로 표시, 선택 당시 자료 해시·인용·불확실성 보존; 등록 시 원본 재검사는 별도 미구현)
- [x] 연결별 초안의 링크 확인·보류 UI와 검토 기록 API, 수정 시 검토 무효화 (검토 내용의 영속 저장은 미구현)
- [ ] 요구사항·분류·이슈 초안 조회, 직접 수정, 대화 제안과 선택 적용
- [ ] 초안 등록 및 revision 충돌 처리
- [x] 등록 문서의 연결·빈 항목 등 결정적 읽기 전용 점검과 상세 조회
- [ ] 의미 검증 API, 근거·불확실성·미처리 구간 표시
- [ ] 검증 결과 해결·보류 사유 저장, revision 변경 시 stale 처리

## 3. 이슈 실행과 운영

- [ ] 실행 대상 미리보기·순차 실행·중단과 실제 이벤트 연결
- [ ] 실행 기록과 검증 근거 저장, 결과 불명 복구
- [ ] 이슈 상태 제안·사용자 적용, 정책 조회·설정·철회
- [ ] 관련 보안·실패 경로와 실제 화면 검증, 타입 검사·테스트·빌드

자료 범위 내의 기계적 연결 표시는 원문 의미의 완전성이나 코드 구현의 증거가 아니다. AI 분석은 조건을 충족하면 선택 자료를 모델 제공자에게 전송할 수 있다. 이슈 실행은 사용자 화면에 아직 연결되지 않았다. 실제 모델 시험의 범위와 잔여 위험은 `ISSUE_ANALYSIS_CONTRACT_V1.md`를 참고한다.
