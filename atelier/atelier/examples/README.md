# 네 프로젝트 범용 UX 검증 예시 · 1.2

홈 → 백업 복원에서 다음 파일을 열면 실제 조작한 가상 프로젝트를 확인할 수 있습니다. 각 `*-prompt.md`는 해당 프로젝트의 확정 통합 프롬프트입니다.

| 파일 | 시작 경로 | 확인한 내용 |
|---|---|---|
| DI-DO.atelier.json | 아이디어부터 | 상태 변경·출력·로그, 수정 결과와 재검토 |
| liar.atelier.json | 이미지부터 | 원본·크롭·적용, 비공개 역할·대화·투표 흐름 |
| worldcup.atelier.json | 컨셉 확정 | 직접 쓴 비교 화면 컨셉, 후보 선택·우승 흐름 |
| survey.atelier.json | 기존 결과 개선 | 가상 결과 직접 등록, 질문·응답·제출·집계 흐름 |

검증용 화면은 HTML을 직접 렌더한 샘플입니다. 실제 고객 자료나 완성된 외부 서비스는 아닙니다. 관찰하지 않은 항목은 확인 불가로 남아 있습니다.

기존 픽셀 게임·네컷 파일은 별도 데모입니다. 새 프로젝트의 기본값으로 복사되지 않습니다.

# 내장 검증 예시

이 자료는 가상의 제품을 설계하는 도구의 사용 예시입니다. 앱의 “백업 복원”에서 `.atelier.json`을 선택하면 원본·파일·참조를 포함해 새 프로젝트로 열 수 있습니다.

- `게임_설계예시.atelier.json`: 픽셀 생존 게임. 반복 탐험·채집·제작·건설, 월드·패널·복구와 스타일 계획. 모든 내장 예시는 제안 상태에서 시작합니다.
- `네컷_수정흐름_검증예시.atelier.json`: 공주풍 Y2K 사진 서비스. 실제 UI 검증에서 기록한 결정·원본·크롭·프롬프트 2개·결과 2개·수정 계획·재검토 관계를 포함합니다.
- `네컷_수정_통합프롬프트.md`: 앱이 실제로 조립한 최신 수정 통합본입니다.
- `범위_서체_파일_검증예시.atelier.json`: 1.1의 실제 분기·복구 연결, 문서·서체·JSON 첨부와 선택 화면의 범위별 출력을 시험한 가상 프로젝트입니다. 선택하지 않은 JSON 자료는 범위별 ZIP에서 제외되고 전체 백업에는 보존됩니다.

네컷 예시의 결과 이미지는 **Atelier 자체 화면을 사용한 QA 픽스처**입니다. 네컷 서비스를 외부에서 실제 제작했다는 자료나 스타일이 일치한다는 검토 결과가 아닙니다. 결과 출처·메모에도 검증용이라고 기록되어 있으며, 새 회차의 판정은 확인 불가 상태로 남겨 두었습니다.

게임의 과금, 네컷의 계정·유료·인쇄 등은 확정하지 않았습니다. 예시를 실제 고객 조사나 공통 제품 요구로 승격하지 마세요.
