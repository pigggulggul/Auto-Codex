## 자연스러운 연결과 검토·수정

시작·빈 상태·완료·실패·대기에서 현재 상황과 가능한 다음 행동을 설명한다. 뒤로 이동하거나 복구할 때 입력과 선택을 유지한다. 버튼은 실제 행동과 결과를 표현한다. 제공하지 않는 동작과 성과를 만들지 않는다. 여러 행동이 필요한 편집기와 게임의 선택 자유를 유지한다.

생성 전 고객과 제공 결과·의문·경험·분위기의 연결을 설명한다. 생성 후 실제 결과를 아래 기준과 비교한다. 각 항목에 기대, 실제 관찰, 화면 또는 영역, 근거와 판정을 기록한다. 색상 하나로 전체 스타일 일치를 판정하지 않는다. 자료가 없으면 확인 불가다.
- intent / 서비스 목적과 전체 경험: DI 입력을 바꿔 DO 상태 변환 규칙과 출력 결과를 확인한다.
- customer / 고객 의문과 판단: 상태·숫자·결과의 의미를 오해할 수 있다는 사용자 가설 / 상태 이름과 결과 설명을 해당 값 옆에 표시하고 사용자가 의미를 구별하는지 확인한다.
- fit / 분위기의 서비스 적합성: 정보와 조작을 빨리 구별해야 해서 — 정보가 또렷한 화면
- style / 색·서체·형태·재질의 관계: 배경: #f4f6f8 → 화면 바탕
본문: #243047 → 본문과 긴 안내
강조: #315ed4 → 주요 버튼과 선택 테두리
서체: sans-serif → 짧은 제목. 긴 한글 본문은 시스템 서체
형태: 8px → 버튼과 패널
배치: 현재 정보와 작업 대상을 위에, 조작 도구를 그 아래에 배치 → 대표 작업 화면
재질: 장식 없는 단색 패널과 얇은 구분선 → 브랜드 그래픽과 지정 리소스
모션: 값과 선택 상태가 바뀔 때만 160ms 전환 → 상태가 바뀌는 컴포넌트
- scope / 지정한 영역과 적용 강도: 화면 바탕 / 예외: 가독성과 조작을 방해하면 강도를 줄임
본문과 긴 안내 / 예외: 가독성과 조작을 방해하면 강도를 줄임
주요 버튼과 선택 테두리 / 예외: 가독성과 조작을 방해하면 강도를 줄임
짧은 제목. 긴 한글 본문은 시스템 서체 / 예외: 가독성과 조작을 방해하면 강도를 줄임
버튼과 패널 / 예외: 가독성과 조작을 방해하면 강도를 줄임
대표 작업 화면 / 예외: 가독성과 조작을 방해하면 강도를 줄임
브랜드 그래픽과 지정 리소스 / 예외: 가독성과 조작을 방해하면 강도를 줄임
상태가 바뀌는 컴포넌트 / 예외: 가독성과 조작을 방해하면 강도를 줄임
- reference / 레퍼런스의 유지와 조정: 등록한 레퍼런스 없음. 직접 규칙으로 검토
- interaction / 정보·조작·복구: DI/DO 보드 상태 변환 시뮬레이터 · UX 검증 사용 순서: 실패한 단계에서 입력을 유지하고 다시 시도
- consistency / 대표 화면과 다른 상태의 일관성: 현재 상태와 선택한 값이 글자로도 구별된다.
잘못 입력하거나 실패해도 입력을 잃지 않고 다시 시도한다.
DI 입력 전환 후 DO 출력이 규칙대로 바뀌고 로그에 값이 기록된다.

불일치 시 원인·수정 범위·유지할 조건을 정한다. 수정본을 같은 기준과 비교하고 영향받는 기존 일치 항목도 다시 확인한다. 결과와 근거 없이 해결을 선언하지 않는다. 시각 검토와 실제 동작 검토는 구분한다. 의도가 바뀌면 이유와 새 기준 버전을 기록한다.
