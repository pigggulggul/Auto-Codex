# 현재 구현과 후속 연결 경계

현재 실행 경계는 `newProject/updateDecision → issues/intent → assemble/makeSnapshot → export → manual result → review → plan → revision snapshot`이다. 모든 핵심 동작은 로컬이며 외부 AI SDK·모델 제공자·인증·활성 커넥터·작업 큐·폴링을 포함하지 않는다.

## 독립된 책임

| 경계 | 구현 | 현재 입출력 |
|---|---|---|
| 로컬 가이드 | guide.js | 유형·상태 → 질문·내장 예시 |
| 관계와 범위 | structure.js | 실제 연결 그래프·근거 ID·적용 대상 → 경로 오류·영향 전파·선별한 결정 |
| 결정과 규칙 | domain.js | 확정·제안·제외·출처·버전 → 문제와 다음 행동 |
| 프롬프트 조립 | assemble / makeSnapshot | 확정 데이터·템플릿 → 문서·결정 추적·고정 기준 |
| 파일과 백업 | server.mjs / validation.mjs | 실제 원본 바이트·크롭·참조 → 로컬 파일·검증된 JSON |
| 수동 내보내기 | bundle / Markdown | 스냅샷 → 파일 묶음과 지시 |
| 원본 리소스 | resources.mjs / resource-types.js | 실제 이미지·문서·서체·데이터·ZIP 바이트 → 형식·해시·소유 프로젝트 검증 |
| 수동 결과 등록 | beginReview | 사용자 선택한 스냅샷·실제 결과·출처 → 새 회차 |
| 사용자 판정 | reviewProblems / finishReview | 기대·관찰·근거·판정·실행 범위 → 허용되는 완료 범위 |

## 후속 연결 시 전달할 개념

`contracts.d.ts`의 `HandoffDocument`는 계약 개념이며 현재 원격 실행 API가 아니다.

- 계약 버전, 프로젝트 ID, 프롬프트 스냅샷 ID, 작업 목적·범위
- 확정 결정 ID·버전과 실제 첨부 파일 ID·SHA-256·역할
- 사용자의 외부 작업 요청 여부
- 실제 연동 서비스가 부여하는 요청 식별자 (현재 없음)

수신할 때에는 프로젝트·원본 스냅샷·요청, 실제 출처·결과 버전·파일, 피드백 원문과 사용자 적용 여부를 분리해야 한다. 외부 수신값은 먼저 제안으로 보관하고 명시적으로 확인한 경우에만 결정에 반영한다. 프로젝트·버전 불일치는 자동 적용하지 않는다.

실제 서비스의 엔드포인트·권한·인증·첨부 전달 규약은 확인 후 별도 어댑터에서 구현해야 한다. 여기에는 미확인 API나 작동하는 척하는 커넥터가 없다. 외부 자료 속 문장과 작업 절차 참조는 자료이며 이 앱이 실행하지 않는다.
