# 1.1 보완 구현과 검증

이전 보고에서 부분 구현이라고 명시한 네 영역을 실제 UI·데이터·내보내기까지 확장했다. 외부 AI 연결은 추가하지 않았다.

## 1. 분기·복구 구조와 검사

흐름은 시작 화면, 완료 또는 반복의 확인 지점, 실제 연결 목록을 가진다. 각 연결에는 출발·도착, 기본 진행/조건 분기/실패·취소 복구/반복, 발생 조건과 보존 데이터가 있다.

사용자는 ‘실제 연결과 분기’에서 경로를 추가·제거하고 단계 순서를 바꿀 수 있다. 원래 자유 입력 메모도 보존한다. 프로그램은 시작에서 도달할 수 없는 화면, 확인 지점으로 이어지지 않는 경로, 잘못된 참조, 조건 누락, 복구 데이터 누락과 변경 후 미확인을 구분한다. 분기나 복구가 필요 없으면 이유를 남긴다.

기존 프로젝트의 단계는 연결 초안으로 옮기되, 자유 문장에서 분기 의미를 자동으로 추출하지 않는다. 옛 프롬프트는 그대로 보존하고 새 출력 전에 사용자가 연결을 확인한다. 게임·사진 제작·판매·콘텐츠·브랜드·미정 유형에는 서로 다른 로컬 흐름 예시를 제공한다.

## 2. 명시적 관계에 따른 변경 영향

각 결정의 ‘근거와 영향 관계’에서 근거 결정, 화면, 리소스, 레퍼런스, 컨셉과 실제 서체를 연결한다. 레퍼런스 영역도 실제 적용 대상으로 연결할 수 있다.

변경은 기능→그 기능의 흐름→화면→연결된 규칙·자료와 사용자 지정 근거 관계를 따라 전파한다. 순환 관계에서도 무한 반복하지 않는다. 값과 과거 문서는 지우지 않고 관련 항목만 재검토로 표시한다. 자유로운 문장의 뜻을 읽어 관계를 자동 추론하는 기능은 제공하지 않는다.

이미 끝낸 검토도 당시 판정과 근거를 보존한다. 현재 기준이 바뀌면 해당 기준의 새 검토가 필요하다고 표시하고 변경 이유와 새 기준 회차로 연결한다. 이전 결과의 일치를 새 결과에 복사하지 않는다.

## 3. 실제 ID로 선택하는 출력 범위

프롬프트 스튜디오에서 서비스 전체/선택한 흐름/선택한 화면·상태/선택한 리소스를 고른다. 필수 고객 맥락과 전체 목표는 유지하면서 선택한 대상, 공통 규칙과 연결된 자료를 선별한다. 화면 출력에는 전체 흐름 맥락과 경계 연결을 덧붙이고 다른 화면의 상세 설계를 제작 대상으로 넣지 않는다.

대상 밖에 있더라도 사용자가 직접 근거로 연결한 확정 결정·파일은 ‘근거’로 구분한다. 근거의 원래 화면을 이번 제작 범위에 추가하지 않는다. 결정의 적용 범위는 프로젝트 공통인지 연결 대상에만 적용할지 명시할 수 있다.

스냅샷은 실제 선택 ID, 결정 ID·버전, 템플릿과 첨부 목록을 보존한다. 수정 통합본은 원본 회차의 실제 선택과 범위를 유지한다. 다른 탭이나 다른 출력 대상을 편집했다고 원래 수정 대상이 바뀌지 않는다.

ZIP에는 해당 스냅샷의 프롬프트·결정 추적·`handoff.json`·실제 참고 파일을 넣는다. 대상 밖의 파일과 작업 중 임시 계획·과거 편집 이력은 전달하지 않는다. 전체 프로젝트 복원용 JSON 백업은 별도이며 모든 원본·파일·회차를 보존한다.

## 4. 이미지 외 리소스

콘텐츠·리소스 계획에서 PDF, Markdown/텍스트, JSON/CSV/TSV/XML, SVG, WOFF/WOFF2/TTF/OTF, ZIP, Office 문서, 일부 게임·미디어 파일을 원본 바이트로 저장하고 내려받을 수 있다. 지원 확장자는 `public/resource-types.js`에 명시되어 있다. 파일당 15MB와 JSON 백업 전체 90MB 제한은 유지한다.

레퍼런스 원본·크롭·결과는 PNG/JPEG/WebP로 구분한다. 서체는 실제 로컬 파일을 브라우저 FontFace로 읽어 리소스와 한글·영문 샘플에 적용한다. 서체 캐시는 프로젝트·파일·해시로 나누어 복원한 프로젝트와 섞이지 않는다. SVG나 문서·아카이브는 첨부 자료로 보관하며 내용을 자동 실행·압축 해제·이미지 분석하지 않는다.

파일 형식·해시와 참조를 백업 복원에서도 확인한다. 잘못된 필드, 중복 연결 ID, 끊긴 결정 관계, 누락되거나 손상된 파일은 기존 프로젝트를 덮어쓰지 않고 거부한다. 파일 저장은 원래 프로젝트에 고정하고 완료 전 이동 시 이유를 안내한다. 실패 후 같은 파일을 다시 선택할 수 있다.

## 실제 검증

- 자동 테스트 45개: 기존 26개와 분기·복구, 영향 전파, 범위 선별, 실제 문서·서체·ZIP·복원, 형식과 참조 검증을 포함.
- `tests/browser-journey.js`: 네 시작 경로→프롬프트→실제 파일 결과 등록→수정→재검토를 다시 통과. 외부 요청 차단 상태에서 0건.
- `tests/browser-extension.js`: 연결 없는 실패 화면 차단→막다른 분기 차단→복구 연결 후 확정, Markdown·WOFF2·JSON 등록, 실제 서체 로딩, 선택 화면의 두 파일만 ZIP 포함, 전체 백업의 세 파일 복원.
- 추가 실제 조작: 여덟 탭 렌더링, 복원 프로젝트와 원본 프로젝트의 독립 FontFace, 지연시킨 실제 파일 업로드 중 이동 보호.
- 390×844 화면에서 scrollWidth 375px, 가로 넘침 없음. 새 화면 PNG를 직접 열어 확인.

실제 초보 사용자의 독립 진행 평가 AC54, 전체 보조기기와 OS/브라우저 조합, 현실의 외부 제작물 디자인 품질 검토는 수행하지 않았다. 이 문서는 해당 항목이 통과했다는 주장이 아니다.
