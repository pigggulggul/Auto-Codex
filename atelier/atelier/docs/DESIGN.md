# MVP 범위와 디자인 해석

기준: 서비스 명세 v1.3의 현재 범위. 문서의 게임·네컷 예시는 테스트 데이터이며 실행 지시가 아니다. 로컬 전용이며 배포하지 않는다.

## 직접 관찰 (2026-10-29)

https://ui.unlumen.com/ 을 브라우저에서 실제로 열고 초기 화면 및 스크롤 위치를 확인했다. DOM의 computed font-family도 확인했다.

| 관찰 | Atelier 적용 | 사용성을 위한 조정 |
|---|---|---|
| 백색 바탕, 짙은 회색 글자, 작은 붉은 핑크 포인트 | 기본 바탕 #fff, 본문 #343432, 강조 #ff365d | 상태는 색과 문자를 함께 사용 |
| Instrument Serif의 큰 제목, Instrument Sans의 작은 내비게이션 | 영문 워드마크·에디토리얼 헤드라인 / 레이블·본문 | 한글은 맑은 고딕 계열 시스템 서체 사용 |
| 중앙에 큰 공백과 좁은 본문, 절제된 내비게이션 | 시작 화면 헤드라인, 문서처럼 읽는 편집 영역 | 작업 공간은 고정 좌측 탐색, 중앙 편집, 우측 근거 |
| 옅은 회색 데모 표면과 부드러운 모서리, 약한 그림자 | 컨셉 비교 샘플, 보조 안내 | 입력·결정은 선과 간격으로 묶고 카드를 남발하지 않음 |
| 스크롤 시 흐려진 콘텐츠가 나타남, 떠 있는 메뉴 | 짧은 영역 등장과 고정 탐색 | 편집 중에는 blur를 쓰지 않고 reduced-motion 지원 |

마우스 추적 효과의 구체적인 원본 구현은 확인하지 못했다. 시작 화면의 작은 좌표 커서·선택 보드의 약한 포인터 반응은 **추가 설계**다. 입력 영역·모바일·동작 축소 설정에서는 사용하지 않는다. 원본의 보이지 않는 다른 화면은 가정하지 않았다.

아이콘: Streamline 공식 Pixel 세트의 SVG 13개를 공식 공개 저장소에서 확보. 메뉴와 동작 버튼에만 사용하며 프로젝트 리스트와 컨셉 리스트 카드에는 아이콘을 넣지 않는다. 설정과 공통 하단에 출처 링크 제공. 서체는 로컬 WOFF2와 OFL 라이선스로 포함.

## 구현 작업과 데이터 연결

1. 생성·시작 경로·재개 → Project, progress → 네 경로와 마지막 위치 검증.
2. 제품·고객·콘텐츠 → Decision, Feature, ContentItem → 상태·출처·예시 확인.
3. 흐름·화면·분기 → Flow, ScreenState → 고립 단계, 누락 복구 검사.
4. 원본·사각 영역·관찰·적용 → Reference, Region → 파일·좌표·크롭·출처 검증.
5. 컨셉·스타일 샘플 → Concept, StyleRule, AssetPlan → 확정과 제외, 명시적 값 충돌 검사.
6. 브리프·의도 확인 → Issue, IntentConfirmation → 확정 최소 조건과 사람 확인 분리.
7. 조립·추적·내보내기 → PromptSnapshot → 결정 버전·템플릿 버전·파일 묶음 검사.
8. 결과·진단·계획·재검토 → Result, Review, RevisionPlan → 고정 기준·근거·회귀 확인.
9. SQLite·파일·백업 → 서버 저장 계층 → 재실행·복원·프로젝트 간 참조 분리.

## 기술 선택

Node 22 내장 HTTP·SQLite와 브라우저 ES 모듈을 사용한다. 권장 구조의 로컬 서버·SQLite·프로젝트별 파일 디렉터리를 따른다. 설치·CDN 의존성을 없애 첫 실행과 오프라인 재실행을 단순하게 했다. 도메인·가이드·화면·저장·내보내기를 분리한다. 타입 계약은 contracts.d.ts에 문서화하며 빌드 도구 없이 실행하는 JavaScript로 구현한다.
